Please implement the following critical changes to the shop/inventory workflow. These are high-priority and should be structured cleanly for future QuickBooks integration.

1) Convert Inventory Intake into Invoice-Based Intake

Goal: Inventory intake should behave like an invoice, not a single-item entry form.

Requirements
Allow multiple inventory line items to be added in a single intake transaction.
Each intake record should support:
Multiple parts/items
Tax amount
Delivery fee / freight fee
Invoice total amount
System should support reconciling/calculating line item subtotal + tax + delivery fee against the final invoice total.
Show validation if totals do not match or are outside an acceptable tolerance.
Store this intake as a structured record that can later map cleanly to QuickBooks bill/invoice syncing.
Data Model Suggestion

Create an inventory_intake header + inventory_intake_items child table pattern:

inventory_intake
vendor
invoice_number
invoice_date
subtotal
tax_amount
delivery_fee
total_amount
reconciliation_status
notes
inventory_intake_items
inventory_intake_id
part/item
qty
unit_cost
line_total
2) Fix Inventory Intake Form Font Color

Goal: Improve usability/readability.

Requirements
Change all light gray form text/labels/placeholders on the inventory intake form to black (or dark, accessible contrast equivalent).
Verify across:
labels
input text
placeholder text (if appropriate)
dropdown text
helper text if currently too light
Acceptance Criteria
Form is fully readable under standard lighting.
Text meets basic accessibility contrast standards.
3) Remove Unnecessary Client Info for Job Orders (When Servicing Internal Fleet)

Goal: Simplify the job order intake form for internal fleet service.

Requirements
Remove or conditionally hide client information fields when the company is servicing its own fleet.
Add a new required field:
Customer Type (dropdown)
Company Fleet
Owner Operator
Third Party
Behavior
Default selection = Company Fleet
4) Add Tractor Database / Lookup by Tractor Number

Goal: Minimize clicks for the shop manager.

Requirements
Create or use a database table for tractors/vehicles, keyed by tractor number.
Add searchable lookup in the job order intake form:
Search by truck/tractor number
Default workflow should assume Company Fleet
When a tractor number is selected/found:
Auto-populate relevant vehicle details (examples depending on current schema):
tractor number
VIN
make/model
year
mileage (if tracked)
assigned driver (if tracked)
unit status / notes (if tracked)
UX Flow
Job order form opens
Customer Type defaults to Company Fleet
User searches by truck number
Matching tractor is selected
Vehicle details auto-populate

Goal: Only show extra fields when needed.

Requirements

Hide client/customer info fields that are not relevant

Requirements

Either create draft invoice automatically

Goal: Shop needs ability to perform physical inventory counts.
